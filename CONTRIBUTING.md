# Contributing

Thanks for helping improve Baller Imposter Game.

1. Open an issue for substantial changes so the approach can be agreed first.
2. Fork the repository and create a focused branch.
3. Run `npm ci`, `npm run lint`, `npm run typecheck`, and `npm run build`.
4. Open a pull request that explains the user-facing impact and testing performed.

Do not add secrets, personal data, copied articles, restricted fonts, or new third-party assets unless you own them or can document their source and reuse terms in the pull request. Image changes must preserve the fallback behavior and update `THIRD_PARTY_ASSETS.md` when applicable.
